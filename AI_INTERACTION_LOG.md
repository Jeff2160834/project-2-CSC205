Day One: I started today with prompting a question in CoPilot to create the abstract Shape3D class to create the base class for the 3D shapes. 
The way I prompted the first question was: "Create a Java abstract class called Shape3D that implements a ThreeDimensionalShape interface. 
The class should have private fields name (String) and color (String) with public getters and setters. Add a constructor that accepts both fields. 
Provide concrete implementations of getVolume() and getSurfaceArea() that simply call their respective abstract methods. Override toString() 
to return a formatted string showing the shape's name, color, volume, and surface area. Include full JavaDoc documentation on all methods and the class itself."

CoPilot generated the code for the Shape3D class based on my prompt. Though CoPolit provided me a couple options after the initial prompt, I chose the one that closely matched my requirements. 
The generated code included each of the shapes I wanted to create, such as Sphere, Cube, and Cylinder, all extending the Shape3D class. Each shape had its own implementation of the getVolume() and getSurfaceArea() methods, as well as a 
toString() method that provided a formatted string representation of the shape's properties. I did have to add the toString method into CoPilot since it did not add it in the initial code generation, but overall, 
CoPilot provided a solid foundation for my project and saved me a lot of time in writing boilerplate code. 

It was very interesting to verify the code that was generated by CoPilot.
